### 射撃場
スタート地点のすぐ後ろ（南）。東端の射撃位置から西へ撃つ細長いレーン。
- 4m・10m・25m・50m・80m の的と床の距離線
- 横に往復する的（18m・40m）
- 弾薬補給所（近づくと予備弾が満タン）
- このほか、壁走り通路のゴール台・スライディング坂の上下・ジグザグ登りの上などにも的を置いた（動きながら撃つ練習用）

### 演出
- 一人称の武器表示（構え・エイム・反動・リロードで弾倉を抜いて差す・ショットガンの先台・スナイパーのボルト操作・持ち替え・ダッシュ時の構え・視点に遅れて揺れる）
- マズルフラッシュと銃口の光、弾道の光跡、着弾の火花、弾痕（8秒で消える）
- 的は撃たれると白く光り、倒すと後ろに倒れ、復活すると起き上がる。頭上に体力ゲージ
- ヒットマーカー（頭は橙、撃破はマゼンタ）、ダメージの数字（頭は大きく橙）、撃破までの時間を記録に表示
- 照準は武器ごとの形（AR/LMG/SMG は十字、ショットガンは円、スナイパーは点と点線の円）で、ばらつきに合わせて広がる
- 効果音（Web Audio で合成）：武器ごとの射撃音、ショットガンの先台・スナイパーのボルト、リロード、持ち替え、空撃ち、命中・頭・撃破、補給

画面の例：`docs/images/` に、モデルの確認画像とゲーム内の画面（腰だめ・ADS・スコープ・命中）を置いた。

## 受け入れ条件の確認

> 武器ごとの違いがわかる。的に当たり判定がある

自動テスト（`npm test`）を 17 項目追加し、移動のテストと合わせて **47 項目すべて合格**。
- 連射速度（AR 1秒で10発、LMG 3秒で約35発。ティックの刻みで連射が遅くならない）、単発武器は押しっぱなしで1発
- 弾切れで自動リロード、リロード時間後に弾倉が満タン・予備弾が減る
- ショットガンは1発ずつ込め、撃てば中断できる
- AR は体に4発で倒せる、スナイパーの頭は 200 ダメージで一撃、SMG は 40m で 45%
- ショットガンは8粒が出て、至近距離で70以上
- 的は体力が回復し、倒すと復活する
- スナイパーの腰だめは 50m でほぼ当たらず、ADS なら必ず当たる
- LMG は撃ち続けると集弾が良くなる、空中・壁走り中はばらつきが増える
- エイム中は移動が遅くダッシュできない、SMG は速く LMG は遅い
- 持ち替え中は撃てない、ホイールで切り替わる

ブラウザでも、射撃場で撃って的に当たり、ダメージの数字と弾道が出ることを確認した。
ただしフェーズ1と同じく作業環境に GPU がないため、**60fps での撃ち心地（反動の強さ・連射の手応え）は未確認**。Esc の調整パネルに「武器」の項目を追加したので、実機で調整してほしい。

## 仕様に書かれていなかったため補った点

1. **予備弾と弾薬補給所**：予備弾を持たせ（上の表）、射撃場に補給所を置いた。スタート地点に戻ったときも満タンになる。
2. **撃っている間・エイム中はダッシュできない**（Shift を押していても走りに戻る）。
3. **ばらつきの細かい規則**：歩き・走りでばらつきが増える（エイム中は影響が小さい）、しゃがむと少し減る、スライディング中は少し増える。連射するとばらつきが広がり、撃ち止めると戻る。
4. **反動**：撃つと視点が上（と左右に少し）に跳ねる。撃ち終わると上に跳ねた分の 45% が自動で戻る。マウスで押さえた分は戻さない。エイム中は反動が小さい。
5. **エイム時のマウス感度**：ズームに合わせて下げ、画面上の動きの速さがそろうようにした。
6. **持ち替え時間**（AR 0.45秒、LMG 0.9秒など）とエイムにかかる時間を武器ごとに設定した。持ち替えるとリロードは中断。
7. **的**：人型（体と頭の当たり判定）、体力 100、自動回復、倒すと復活。
8. **当たり判定は「ヒットスキャン」**（撃った瞬間に届く）。光跡は見た目だけ弾の速さで飛ぶ。
9. **装備の変更**：本来はフェーズ3の「キャラクター・装備選択画面」の役目だが、5種類を試せるよう、一時停止画面にメイン・サブを選ぶ欄を先に入れた。
10. **効果音を先に入れた**（仕様ではフェーズ8）。武器ごとの違いが音でもわかるようにするため。足音などの移動の音はフェーズ8で。
11. ~~近接攻撃（V）とグレネード（G）は未実装~~ → 追加実装で対応（下の「追加実装」）。

## 3Dモデル（Blender）について
- 作業環境に Blender の Python モジュール（bpy 5.0）を入れ、スクリプトからモデルを作って `.glb` で書き出した。
- 武器：`assets-src/weapons/build_weapons.py` → `client/assets/weapons/*.glb`
- 的・弾薬補給所：`assets-src/props/build_props.py` → `client/assets/props/*.glb`
- 作り直すときは `npm run models`（Python 3.11 と `pip install bpy` が必要）か、Blender 本体で `blender --background --python <スクリプト>`。`--blend` を付けると確認用の .blend も保存する。
- 形は基本図形の組み合わせ（ローポリ）に面取りと発光ラインを付けたもの。ネオン都市の雰囲気に合わせ、武器ごとに差し色を変えた（AR シアン、LMG オレンジ、SMG マゼンタ、ショットガン アンバー、スナイパー 紫）。

## 追加実装（フェーズ2の修正依頼）

### ① グレネードと格闘
**グレネード（G）**
- G を押している間は構え、離すと投げる。構えている間は、飛んでいく軌道（光る点の列）と、落ちる位置・爆風の範囲の輪を表示する。軌道の予測はゲームロジックと同じ計算なので、表示どおりに飛ぶ。
- 視線より 9° 上へ 19m/秒 で投げ、自分の移動速度の半分を引き継ぐ（走りながら・壁走りしながら投げると遠くへ飛ぶ）。
- 地形や的に当たって跳ね返り、転がって止まる。投げてから 3 秒で爆発。点滅は爆発が近いほど速くなる。
- 爆風は半径 6m。1.5m 以内は 110、外側へ向かって 20 まで下がる。間に壁があれば届かない。
- 所持数 2。6 秒で1つ回復し、弾薬補給所とスタート地点では満タンになる。
- 構えている間は撃てず、エイム・ダッシュもできない。リロードは中断する。
- 演出：手に持つグレネード（構えるとピンが抜ける）、投げる動き、閃光・火球・地面を走る衝撃波・破片・煙・焦げ跡・光、画面の揺れ（近いほど強い）、ピンを抜く音・投げる音・跳ねる音・爆発音（遠いほど小さくこもる）。
- モデルは Blender で作成（`assets-src/props/build_props.py` の `build_grenade`）。

**格闘（V）**
- 正面 40° 以内・1.9m 以内の的を殴る。ダメージ 100（的は一撃）。
- 3.2m 以内なら、的へ 7m/秒 で踏み込んで殴る。
- 0.75 秒は次を殴れず、殴った直後 0.4 秒は撃てない。リロードは中断する。
- 的がいなければ目の前の壁を殴る（火花と音だけ）。間に壁があれば殴れない。
- 演出：銃を左へ振って銃床で突く動き、当たったときの手ごたえ（画面の揺れ・火花・音）。

### ② 予備弾を無限に（リロードは必要）
- 予備弾が減らなくなった。弾倉が空になればリロードが必要なのは変わらない。HUD の予備弾は「∞」と表示する。
- `config/weapons.json` の `COMMON.INFINITE_RESERVE` を `false` にすると、元の有限の予備弾に戻る（調整パネルの「武器」にも切り替えあり）。

### 補った点
- **グレネードは投げた時点から爆発までの時間を数える**（構えている間は数えない）。手の中で爆発することはない。
- **格闘のダメージは 100**（参考にしたタイタンフォールのパイロット同士の格闘に合わせ、的は一撃）。強すぎる場合は `MELEE_DAMAGE` で下げられる。
- **グレネードの回復（6秒で1つ）** は、テスト部屋で何度も試せるように入れた。対戦では `GRENADE_REGEN_TIME` を 0 にすれば回復しなくなる。
- **自分はダメージを受けない**（プレイヤーの体力はフェーズ6で入れるため）。自分のグレネードの爆風も今は当たらない。

### 確認
自動テストを 13 項目追加し、合計 **60 項目すべて合格**（予備弾が減らないこと、弾倉が空のあいだは撃てないこと、構えと投げ、放物線と跳ね返りと爆発までの時間、爆風の強さと届く範囲、壁で遮られること、的を倒せること、所持数と回復、構えている間は撃てないこと、格闘のダメージ・踏み込み・届かない範囲・連打できないこと）。
ブラウザでも、軌道の表示・爆発で的にダメージが入ること・格闘で的を倒せることを確認した。
